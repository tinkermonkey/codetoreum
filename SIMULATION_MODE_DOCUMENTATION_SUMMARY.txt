KEY INSIGHTS:
=============

1. ARCHITECTURE: Hexagonal architecture with clear separation
   - Domain layer: Pure business logic (no external dependencies)
   - Application layer: 8 orchestration services
   - Ports layer: 15 input/output port interfaces
   - Adapters layer: 9 mock adapters for testing
   - Infrastructure layer: Event bus, clock, logger

2. BOOTSTRAP: Single entry point wires entire stack
   - Critical initialization order (Infrastructure → Adapters → Services → Ports → App)
   - Dependency injection through constructor parameters
   - Data containers for organizing components
   - Async setup/teardown for proper resource management

3. TIME MANIPULATION: Core differentiator from real execution
   - SimulationClock with speed multipliers (1x-100x+)
   - Callback scheduling for time-based events
   - Thread-safe implementation with RLock
   - 10-100x faster execution without sacrificing determinism

4. TESTING STRATEGY:
   - Unit tests: Domain models (existing)
   - Integration tests: Services with mocks (existing)
   - Simulation tests: Isolated scenarios (existing)
   - E2E tests: Full stack via REST/WebSocket (Phase 3)
   - CLI testing: Interactive server (Phase 4)

5. OBSERVABILITY: Three layers
   - Event sourcing: Complete audit trail in InMemoryEventStore
   - Metrics: Prometheus-style metrics collection
   - WebSocket: Real-time event streaming
   - REST APIs: Query metrics and events
